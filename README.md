# Recovery Parts — sitio web + campus virtual

Academia de cursos y talleres técnicos. Next.js 16.4.2 + React 19 + Tailwind 4 + Postgres propio (sin ORM) + archivos en volumen, desplegado con Docker Compose en Coolify.

- Sitio público: `/`, `/cursos`, `/cursos/[slug]`, `/galeria` (contenido desde el CMS).
- Campus: `/login` → `/campus/{admin,profesor,alumno}` (autorización por rol en servidor + RLS en Postgres).
- No incluye pagos, inscripciones, asistencia ni stock (los maneja software externo).

## Desarrollo
```bash
npm install
npm run setup:dev   # crea .env.development (no se versiona) con un SESSION_SECRET propio
npm run db:start    # Postgres local en Docker (docker-compose.yml, solo la base, puerto 54322)
npm run db:migrate  # aplica db/migrations
npm run seed:dev    # cuentas y cursos de prueba (opcional)
npm run dev         # http://localhost:3000
```
Requiere Node 22 (el Dockerfile y el CI usan 22) y Docker. Entornos y ramas: `docs/ENTORNOS.md`.

## Calidad (estándar CodeTlon)
CI (`.github/workflows/ci.yml`): tipos + lint + build, migraciones desde cero con reglas de RLS y **reglas de negocio de la base** (`tests/db/reglas.sql`), imagen Docker y **E2E en 3 viewports con base de datos** (89 pruebas: humo, acceso/activación/logout, CSP, formularios públicos y campus por rol con acciones del admin; `npm run test:e2e`, los que usan datos piden `DATABASE_URL` y `SESSION_SECRET`), `npm run test:unit` y un job de Firefox y Safari. Workflows de entorno: `entornos.yml` (push a `test`: espera el deploy y corre los E2E contra `TEST_URL`; si `test` está apagado avisa y no falla), `produccion.yml` (smoke de producción, llave `PRODUCCION_HABILITADA`) y `backup-check.yml` (alarma diaria de backup en B2). `npm audit --omit=dev --audit-level=high` en 0.
